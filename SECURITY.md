# Report a vulnerability

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/pplytas/good-webhooks/security/advisories/new). Include the affected commit or version, impact, and a minimal reproduction. Keep security reports out of public issues and pull requests.

Good Webhooks is in beta. Security fixes target the latest beta release; older pre-release versions have no maintenance branches. From `0.1.0`, security fixes reach the latest minor and the previous minor for three months after the next minor ships, as described in the [compatibility policy](apps/docs/content/docs/operations/compatibility.mdx). Upgrade guidance and affected versions belong in the advisory and release notes.
