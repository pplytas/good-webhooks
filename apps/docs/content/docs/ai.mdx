Every page is available as plain Markdown. Coding agents read it more reliably than HTML.

| Resource                           | What it is                                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------------------ |
| [`/llms.txt`](/llms.txt)           | An index of every page, grouped by section, with links to the Markdown versions            |
| [`/llms-full.txt`](/llms-full.txt) | All the docs in one Markdown file                                                          |
| `/docs/<page>.md`                  | Any page: add `.md` to its URL, for example [`/docs/quick-start.md`](/docs/quick-start.md) |
| `Accept: text/markdown`            | Any page URL returns Markdown when the request prefers it                                  |
| **Copy Markdown** and **Open in**  | Buttons at the top of every page. Send the page to ChatGPT, Claude, Cursor, and others     |

The Markdown includes the type-checked example files and the generated type tables, so an agent sees the same code you do. The docs describe the latest alpha; pin that version.

## Add the rules to your project

Paste this into your `AGENTS.md`, `CLAUDE.md`, or your editor's rules file. It points the agent at the docs and lists the mistakes agents make most often with this library.

```md title="AGENTS.md"
## Good Webhooks

Docs: https://good-webhooks.vercel.app/llms.txt (fetch the linked .md pages for details)

- Receivers must pass the raw request body (string or bytes) to `parseWebhook()`. Never parsed JSON.
- Receivers must record `event.id` in the same transaction as their change. Delivery is at least once.
- Respond 400 only for SIGNATURE_INVALID, SIGNATURE_EXPIRED, PAYLOAD_INVALID. Other errors are 500 so the sender retries.
- `publish()` only stores the event. Nothing is sent unless a worker runs `worker.run()` or `worker.runOnce()`.
- Load `WEBHOOK_ENCRYPTION_KEY` from secrets. Never call `generateEncryptionKey()` at startup.
- Apply SQL from `getPostgresMigration()` with the migration tool. The library never runs migrations.
- `forScope()` does not authorize. Check the caller's access before choosing a scope.
- Publish with `{ transaction: client }` when the business write uses the same database.
- `allowLocalhost: true` is for local development only.
```
