title: Installation
description: Add Good Webhooks to an existing application. Install, create a key and the tables, and connect.
---

**Requirements:** Node.js 24 or later, and PostgreSQL 16 or 17 for delivery and standalone endpoint management. TypeScript needs 5.9.3 or later with `moduleResolution` set to `NodeNext` or `Bundler`. Edge runtimes are not supported.

<Steps>
<Step>
### Install

<Tabs groupId="setup" persist items={['PostgreSQL', 'Better Auth', 'Receiver only']}>

```package-install

```

```package-install

```

</Tab>


</Tab>

```package-install
good-webhooks zod
```

</Tab>
</Tabs>

Payload schemas can use any [Standard Schema](https://standardschema.dev) library; these docs use Zod.

</Step>
<Step>
### Create a storage key

This key encrypts endpoint signing secrets in your database. Generate it once:

```sh
node -e 'import("good-webhooks").then(m => console.log(m.generateEncryptionKey()))'
```

Store the output in your secret manager or `.env` as `WEBHOOK_ENCRYPTION_KEY`. Every process that sends or manages webhooks needs the **same** key.

</Step>
<Step>
### Create the tables

Write the SQL to a migration file, then apply it with your migration tool or `psql`:

```sh
node -e 'import("good-webhooks/migrations").then(m => process.stdout.write(m.getPostgresMigration()))' > 001-webhooks.sql
psql "$DATABASE_URL" --single-transaction -v ON_ERROR_STOP=1 -f 001-webhooks.sql
```

The tables are prefixed `webhook_` and go in `public`. To use another schema, see [migrations](/docs/operations/migrations).

</Step>
<Step>
### Create the client

```ts title="webhooks.ts"
import { createWebhooks } from 'good-webhooks'
import { Pool } from 'pg'
import { z } from 'zod'

export const pool = new Pool({ connectionString: process.env.DATABASE_URL })

export const webhooks = createWebhooks({
  database: pool,
  encryptionKey: process.env.WEBHOOK_ENCRYPTION_KEY!,
  events: {
    'invoice.paid': z.object({ invoiceId: z.string(), amount: z.number().int() }),
  },
})
```

Check the schema at startup. It throws `SCHEMA_MISMATCH` if the tables are missing or outdated:

```ts
await webhooks.check()
```

</Step>
