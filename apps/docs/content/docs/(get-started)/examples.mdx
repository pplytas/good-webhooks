## Try the Playground

[playground.good-webhooks.dev](https://playground.good-webhooks.dev) is a public app built on the published package. Sign in with GitHub, add an HTTPS endpoint, and receive signed `clock.ticked` and `ping.requested` events within minutes, with delivery history, retries, replay, and test events in the browser. Its [source](https://github.com/pplytas/good-webhooks-playground) is a complete Next.js and worker deployment, and it is where the library is dogfooded.

## Run locally

You need Node.js 24, npm, and Docker with Compose. In the example directory:

```sh
npm ci
docker compose up -d --wait
npm run setup
npm run dev
```

Open `http://127.0.0.1:4311` for order fulfillment or `http://127.0.0.1:4312` for billing. Keep the generated `.env` between restarts: it holds the key that encrypts registered endpoint secrets. Each README has a walkthrough and test instructions.
