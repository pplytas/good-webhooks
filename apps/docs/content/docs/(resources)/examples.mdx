## Run locally

You need Node.js 24, npm, and Docker with Compose. In the example directory:

```sh
npm ci
docker compose up -d --wait
npm run setup
npm run dev
```

Open `http://127.0.0.1:4311` for order fulfillment or `http://127.0.0.1:4312` for billing. Keep the generated `.env` between restarts: it holds the key that encrypts registered endpoint secrets. Each README has a walkthrough and test instructions.
