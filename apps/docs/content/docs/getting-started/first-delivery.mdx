---
title: Send your first webhook
description: Install the package in a fresh application and deliver a signed event to a local receiver.
---

Create an endpoint, publish an invoice event, and verify the signed request at a local receiver.

Use Node.js 24 or later, npm, and Docker. Create the local package archive with the [installation guide](/getting-started/installation#create-an-archive).

## Create an application

Run these commands in a new directory. Replace the archive path with your local path.

```sh
mkdir good-webhooks-tutorial
cd good-webhooks-tutorial
npm init -y
npm install /absolute/path/to/good-webhooks-0.1.0-alpha.1.tgz pg zod
```

## Start PostgreSQL

Start a fresh, disposable PostgreSQL 16 database:

```sh
docker run --name good-webhooks-tutorial \
	-e POSTGRES_PASSWORD=webhooks_dev_only \
	-e POSTGRES_DB=webhooks \
	-p 127.0.0.1:55439:5432 \
	-d postgres:16
export DATABASE_URL='postgres://postgres:webhooks_dev_only@127.0.0.1:55439/webhooks'
```

If port `55439` is occupied, choose another host port and update `DATABASE_URL` to match.

Wait until this command prints `accepting connections`:

```sh
docker exec good-webhooks-tutorial pg_isready -U postgres -d webhooks
```

## Apply the migration

Generate the combined management and delivery migration from the installed package. Apply it once to the fresh database with the container's `psql`:

```sh
node --input-type=module -e 'import { getPostgresMigration } from "good-webhooks/migrations"; process.stdout.write(getPostgresMigration())' > 001-webhooks.sql
docker exec -i good-webhooks-tutorial psql -U postgres -d webhooks \
	--single-transaction -v ON_ERROR_STOP=1 < 001-webhooks.sql
```

The output lists the tables and indexes created by the migration. For an existing application, use its [migration runner](/operations/migrations).

## Create the receiver and sender

Save this file as `first-delivery.mts`. Node.js 24 runs it directly.

```ts title="first-delivery.mts"
import assert from 'node:assert/strict'
import { once } from 'node:events'
import { createServer } from 'node:http'
import { Pool } from 'pg'
import { z } from 'zod'
import { createWebhooks, generateEncryptionKey } from 'good-webhooks'
import { parseWebhook, WebhookError } from 'good-webhooks/verify'

const events = {
  'invoice.paid': z.object({ invoiceId: z.string(), amount: z.number().int().nonnegative() }),
}
const pool = new Pool({ connectionString: process.env.DATABASE_URL })
const webhooks = createWebhooks({
  database: pool,
  events,
  encryptionKey: generateEncryptionKey(),
  allowLocalhost: true,
})
let endpointId: string | undefined
let endpointSecret = ''
let receivedEventId: string | undefined

const receiver = createServer(async (request, response) => {
  try {
    const chunks: Buffer[] = []
    let size = 0
    for await (const chunk of request) {
      const bytes = Buffer.isBuffer(chunk) ? chunk : Buffer.from(chunk)
      size += bytes.length
      if (size > 512 * 1024) {
        response.writeHead(413).end()
        return
      }
      chunks.push(bytes)
    }
    const event = await parseWebhook({
      body: Buffer.concat(chunks),
      headers: request.headers,
      secret: endpointSecret,
      events,
    })
    receivedEventId = event.id
    console.log(`Received ${event.type}: ${event.data.invoiceId}, amount ${event.data.amount}`)
    response.writeHead(200).end('accepted')
  } catch (error) {
    console.error(error)
    const invalidRequest =
      error instanceof WebhookError &&
      ['SIGNATURE_INVALID', 'SIGNATURE_EXPIRED', 'PAYLOAD_INVALID'].includes(error.code)
    response.writeHead(invalidRequest ? 400 : 500).end()
  }
})

try {
  await webhooks.check()
  receiver.listen(0, '127.0.0.1')
  await once(receiver, 'listening')
  const address = receiver.address()
  assert(address && typeof address !== 'string')

  const created = await webhooks.endpoints.create({
    url: `http://127.0.0.1:${address.port}/webhooks`,
    eventTypes: ['invoice.paid'],
  })
  endpointId = created.endpoint.id
  endpointSecret = created.secret
  const publication = await webhooks.publish({
    type: 'invoice.paid',
    data: { invoiceId: 'inv_123', amount: 4200 },
  })
  assert.equal(publication.deliveryCount, 1)
  const result = await webhooks.worker.runOnce()
  assert.equal(result.succeeded, 1)
  assert.equal(receivedEventId, publication.eventId)
  console.log('Delivery succeeded with a verified signature.')
} finally {
  try {
    if (endpointId) await webhooks.endpoints.remove(endpointId)
  } finally {
    await new Promise<void>((resolve) => receiver.close(() => resolve()))
    await pool.end()
  }
}
```

The receiver authenticates the original request bytes before it reads the invoice payload. The worker sends the request only when you call `runOnce()`.

## Send the event

```sh
node first-delivery.mts
```

The program prints:

```text
Received invoice.paid: inv_123, amount 4200
Delivery succeeded with a verified signature.
```

The program removes its endpoint and closes the receiver and database pool. Each run creates a new endpoint and event.

The temporary encryption key and `allowLocalhost: true` suit this disposable tutorial. For a persistent application, [save one encryption key and configure your workers](/operations/workers). Before adding receiver business logic, [commit a receipt and the business changes together](/delivery/receiving#commit-receiver-work-before-acknowledging-it) so retries cannot repeat the changes.

## Stop PostgreSQL

Remove the tutorial's disposable database when you finish:

```sh
docker rm -f good-webhooks-tutorial
```

For transaction rollback, retry, replay, and durable receiver deduplication, run the [full repository demo](https://github.com/pplytas/good-webhooks/blob/main/packages/good-webhooks/examples/basic/demo.ts) with the [README instructions](https://github.com/pplytas/good-webhooks#try-the-example). To integrate publication into your application, follow [Publish events](/delivery/enqueue).
